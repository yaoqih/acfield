# 80 mm AprilTag PNG

12 张 tag36h11，ID 10–21。每张 1600 × 1600 px，508 dpi（20 px/mm），成品 **80 × 80 mm**；黑框 **72 × 72 mm**，每侧白边 **4 mm**，无出血。按实际大小打印，禁用适应页面；打印后尺量黑框。PNG 的 DPI 元数据可能被打印软件忽略，应同时指定 80 mm 输出边长。

图案标准上边朝车头 +X；没有额外文字和方向箭头。车顶四个内侧安装孔落在图案内，必须先解决平整贴装方式。4 mm 白边比官方源图的一单元白边窄，数字解码成功不能证明实拍可靠；请在实际全场相机下检查视角、反光、运动模糊和识别裕量。

视觉 `size_m` 使用实测黑框边长，名义 `0.072`；高度按装车实测。ID 10–13 可用于四辆车，ID 18–21 尚未加入默认配置；同场不得出现重复 ID。现有 104 mm 旧标签配置不会自动改变，地面标签另行配置。

源图统一保存在 `assets/apriltags`，来源、哈希及 BSD-2-Clause 许可见该目录与 `THIRD_PARTY_NOTICES.md`。从仓库根目录运行：

```sh
uv run python hardware_design/acrylic_95/tag_images/generate.py
```

脚本重建 PNG 与 ZIP，核对源图哈希、输出像素/物理尺寸，并用 OpenCV 的 AprilTag 36h11 字典对全部 12 张图进行四方向数字解码。该检查验证生成文件的数字内容和旋转可译码性，不替代实际相机、打印质量和安装后的识别验收。
