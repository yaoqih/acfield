# 95 mm 方案：尺寸、装配与动力核算

本文对应本目录已提交的两份 DXF，不是旧 V11 打印版。长度单位为 mm，质量单位为 g。坐标、板厚和理想接触几何可以由图纸复核；采购件尺寸、重量、摩擦与刚度仍是条件输入。

## 1. 坐标与实际外廓

原点在顶板几何中心的地面投影，X 正向为车头，Y 正向为车体左侧，Z 从地面向上。图中 X 向右。底板范围 X = −47.5…+47.6、Y = −40…+40；顶板 X = ±47.5、Y = ±40。底板多出的前向 0.1 mm 是球轮圆形支撑鼻的结果。两个轮子直径是 **34 mm，半径 17 mm**。

驱动轮轴在 X = −30.5，两个轮心在 Y = ±36.75，名义轮心距 73.5。假设轮胎宽 6.5，其横向外侧正好到 ±40；前后轮胎范围为 −47.5…−13.5。因此名义硬件平面范围约 95.1 × 80，但这未计螺丝头、外露轴、轮胎变形、接头与线束。采购的轮毂装轴深度改变时，轮距和总宽都会变化。

球轮中心在 (+26.5, 0)，距驱动轴 57。底板对球轮法兰按直径 40.2 支撑，轮胎区域对侧面和后缘均开放，没有电机本体凹槽，也没有独立电机托架孔。电机直接使用原配支架，支架用 M2 固定到底板。

## 2. 孔位表

以下为孔中心，不是螺钉外径；相同的 ± 组合全部保留。圆孔、封闭槽和外轮廓均为切穿路径，不刻字、不加花纹，不将审核图导入切割机。

| 板件 / 功能 | 中心坐标 (X, Y) | 孔或槽 | 数量 |
| --- | --- | --- | --- |
| 两板 / 外侧支柱 | (±43, ±27.5) | Ø3.6，M3 间隙孔 | 每板 4 |
| 顶板 / 主板悬挂柱 | (±24.5, ±29) | Ø3.6；中心距 49 × 58 | 4 |
| 底板 / 电机支架 | (−39.75, ±18)、(−21.25, ±18) | Ø2.6；同侧前后孔距 18.5 | 4 |
| 底板 / 球轮主体 | (+26.5, 0) | Ø22.8 | 1 |
| 底板 / 球轮紧固 | X = +26.5；Y = −16…−14、+14…+16 | 槽宽 3.6，总长 5.6；允许螺钉中心距 28…32 | 2 |
| 底板 / 电池绑带 | (+1, ±30.5) | 6 × 3 圆头槽，6 沿 X | 2 |

电池四周的专用立柱孔已取消，保留这一对绑带槽。绑带需柔软、不导电，穿过电池上方时限制高度，避免压伤软包电芯。这里的 3 mm 槽宽限制绑带厚度，6 mm 槽长限制带宽；不能直接假定普通宽魔术贴可穿过。

最小内孔间材料桥约 **0.8**，位于球轮 Ø22.8 中孔与紧固槽之间；最小孔到外缘材料约 **2.7**。它们说明路径没有重叠，不能证明亚克力在螺母夹紧和冲击下足够强。球轮法兰与垫片的接触面、槽附近裂纹需要首件检查；若不合格，应改孔位或材料并重出 CAD，不能靠进一步拧紧解决。

## 3. 高度链与主板朝向

| 部位 | 名义距地 Z | 依据 |
| --- | --- | --- |
| 驱动轴 | 17 | 34 mm 轮在平地滚动 |
| 底板下表面 / 上表面 | 8 / 12 | 板厚 4；支架轴高假设为板上 5 |
| 电池底 / 顶 | 12.5 / 32.5 | 0.5 软垫 + 20 厚电池 |
| 电池绑带最高处 | 33.5 | 再计 1 厚绑带 |
| 主板上表面参考 | 42 | 顶板下表面减 15 悬挂柱 |
| 顶板下表面 / 上表面 | 57 / 59 | 12 + 45 外柱，再加 2 板厚 |

用四根 **M3 双通 45 mm** 外柱把顶板固定到底板；用四根 **M3 双通 15 mm** 柱把主板悬挂在顶板下方。主板元件朝上，15 mm 柱从主板上表面连接顶板下表面，不能把板倒置来套用这条高度链。主板 49 mm 孔距沿 X、58 mm 沿 Y；这相对历史主板包络再旋转 90°，用于让两排较长针脚避开电池。

审核使用供应商 STEP 中逐个元件的历史包围盒，按实际电池投影筛选最低元件；电池上方局部元件下探约 3.5，故间隙为 `42 − 3.5 − 32.5 − 1 = 5`。不能把主板全局最低针脚的 9.41 下探高度，直接套到整个电池上；也不能忽略它在其他区域的碰撞。最高元件约高出主板 12.9，离顶板只有 `57 − 42 − 12.9 = 2.1`。悬挂柱到局部元件的模型侧隙仅约 **0.32**，需要核实真实柱对边尺寸、元件位置及装配误差。

这也是本版没有再降 10 mm 的原因：上方净空已经小，完整插头、天线、USB 插线和弯线空间也未计全。电池高度、软垫、绑带或主板安装面变化，必须重算；柱高不是仅看 PCB 板面间距就能决定。

### 编码器与底板需要单独核对

电机轴心在底板上方 5，而编码器若是以轴心为圆心的 Ø12 包络，其最低点为 `5 − 6 = −1`，可能侵入底板约 1。减速箱“底部到轴心 5 mm”不能证明后端编码器也可贴板安装。当前 CAD 无电机槽，不能宣称已避让。先拿实际电机、支架和纸样比对编码器位置；若确实干涉，需选择局部避让或改变安装高度，同时重算离地、球轮、主板和柱高。

## 4. 顶板标签与螺丝冲突

80 × 80 标签居中时覆盖 X、Y = ±40；72 mm 黑框覆盖 ±36。四个悬挂孔 (±24.5, ±29) **全部在黑框内部**。普通圆头 M3 螺丝直接压在标签下面会使纸面起伏，标签挖孔也会破坏编码区域。审核图和爆炸图已把这些位置标红；原图纸的孔位保持如实记录，没有把问题从图中藏掉。

建议先评估“顶面齐平的悬挂紧固 + 平整不透明标签载体”，再决定是否修改 CAD。2 mm 亚克力直接做 M3 沉头会削弱孔周材料，不能只换沉头螺丝就认定解决。粘接悬挂点、独立标签载体或移孔均会改变工艺/零件，需要选择并完成首件后更新图纸。本次文件尚未定义其中任何一种为已验证方案。

外侧孔 X = ±43，在标签外侧。若螺丝头直径 5.5，则距标签边名义仅 0.25；若垫片外径 6，则名义相切。实际偏心、垫片和翘边都可能侵入白边。不能只看孔中心在标签外就确认可装。

## 5. 重量、重心与接地载荷

审核脚本按两张 DXF 的净材料面积和 PMMA 密度 1.18 g/cm³ 计算底板约 **30.84 g**、顶板约 **17.73 g**，合计约 **48.57 g**。板厚、材料密度和供应商余量变化会改变实重。

| 模型输入 | 质量与重心假设 |
| --- | --- |
| 电池 | 90，X = −2、Z = 22.5；不是已确认商品 |
| 主板（含简化元件） | 40，X = 0、Z = 50 |
| 两电机与简化支架 | 每组 21，X = −30.5、Z = 17 |
| 两轮合计 | 4，X = −30.5、Z = 17 |
| 球轮 | 20，X = +26.5、Z = 8 |
| 外柱与悬挂柱 | 按对边 5.5、内孔 Ø3、尼龙密度 1.15 g/cm³ 估算 |
| 线束、电源小件、其余紧固、标签 | 合计 22，分布见 `review.py` |

`M = Σm`，`Xcg = Σ(mX)/M`，`Zcg = Σ(mZ)/M`。据此总质量 **271.85**，重心 **X = −3.91、Z = 25.91**。球轮静载比例 `(Xcg − Xaxle)/(Xcaster − Xaxle) ≈ 46.66%`，两主动轮合计约 **53.34%**，左右对称时各约 26.67%。球轮并非只承受少量载荷，其摩擦与万向滚动质量会明显影响跟踪。

按理想刚体和水平地面，前进加速绕后轴翘头的阈值约 `g × 26.59/25.91 = 10.07 m/s²`；前进制动绕前球轮的纵向阈值约 `g × 30.41/25.91 = 11.51 m/s²`。这只核算纵向静力矩，未包含三角支撑侧翻、颠簸、轮胎抓地、结构弹性和冲击，**不能作为控制加速度上限**。实际往往先打滑或跟踪失效。更低、更靠近驱动轴的电池有助于降低惯量和增加主动轮载荷，但要同时保留球轮接地和制动稳定性。

## 6. 电机减速比与速度边界

本节是不同减速比的名义对比，不是实车性能保证。四辆验证车现已由 1:100 更换为 **1:20 电机 ×2**，与 CAD 首件候选一致。先核对供电电压、轮径和编码器计数，再在额定线速度以下逐步测试。

按用户提供的 A12、12 V 参数表和 34 mm 轮计算，不把空载速度当作可用闭环速度：

| 减速比 | 额定转速 rpm | 额定扭矩 mN·m / 台 | 额定点线速度 m/s |
| --- | --- | --- | --- |
| 1:20 | 500 | 14.7 | 0.89 |
| 1:30 | 380 | 19.6 | 0.68 |
| 1:50 | 230 | 39.2 | 0.41 |
| 1:100 | 130 | 78.4 | 0.23 |
| 1:150 | 85 | 117.6 | 0.15 |

速度换算 `v = π D n / 60`。1:20 空载 1100 rpm 对应约 1.96 m/s，但不能用作带车、转弯和低电量下的目标速度。两台额定扭矩换算轮缘合力 `2 × 0.0147 / 0.017 ≈ 1.73 N`，除以 0.272 kg 得到 6.36 m/s²；它仍未扣滚阻、球轮阻力和转动惯量，不是实车加速度保证。

对于更换后的 1:20 验证车，先在架空状态确认方向和编码器计数，再从低速开始分级测试。主控默认限速为 0.50 m/s、1.50 rad/s，固件线速度及轮速上限为 0.89 m/s、角速度上限为 3.00 rad/s；加速度限制已移除。每一级都要记录稳态误差、启动死区、两轮一致性、弧线、原地转向、电流、温升和低电压表现。参数表中的额定电流和堵转电流也要按当前电机复核，堵转点不能持续使用。

转弯还受轮速上限约束：`vR = v + ωb/2`、`vL = v − ωb/2`。两轮均需落在可用闭环范围内；速度接近极限时，角速度余量会变小。使用共同缩放保持左右轮速比例，避免分别硬裁剪造成轨迹曲率改变。

## 7. 如何贴近 unicycle 模型

模型 `ẋ = v cosθ, ẏ = v sinθ, θ̇ = ω` 的参考点是两驱动轮轴中点。前支撑球轮只是承重，不改变这个参考点；把主动轮后移不会让任意车体中心自动满足该模型。

标签居中时，它在驱动轴前方 **30.5 mm**。控制端需要的是“轴中点到标签中心”的车体系位移，名义 `(0.0305, 0) m`，再按真实贴装实测。视觉位置应减去旋转后的位移；不做补偿会把原地转向时标签绕轴的运动误当成车体平移。车体包络也应相对轴中点配置，前伸约 78.1、后伸约 17，不能只放一个以轮轴为中心的 95 mm 矩形。

效果取决于左右轮同轴、等效轮径、有效轮距、球轮阻力、减速器回差和速度闭环。电机减速比改变后，必须实测编码器每轮转计数；7 PPR、AB 相和四倍频是不同计数口径，不应只乘商品名称中的“20”。机械装好后测长直线、顺逆时针原地转向和不同半径圆弧，再辨识有效轮径、轮距、死区与延迟。

## 8. 首件装配到四车

1. **纸样和量具检查**：按 1:1 打印底板、顶板，拿实物核对轮毂插入、支架 M2 孔、编码器、CY-12B、主板两排接口和电池出线。先解决本页标出的三个结构问题，再订成套板材。
2. **一套板件试装**：4 mm 底板、2 mm 顶板，边缘去毛刺。用盘头螺丝和薄平垫片轻夹，防止亚克力开裂；尼龙螺丝装配后检查松动与蠕变，不照搬金属螺栓扭矩。
3. **断电接线**：3S 满充 12.6 V；板卡宣传输入上限 13 V，需核对具体版本与电机反电动势裕量。检查电源极性、保护和开关。ZH1.5/PH2.0 只说明间距，不保证针序；对照板端定义逐线核验电机、编码器电源、A/B。
4. **架空及单车**：测编码器方向和计数、轮速闭环、断链/指令过期停车、供电压降及温升。先低速，再测制动、轮胎滑动和球轮运动；每台车分别标定。
5. **真实视觉**：黑框名义 0.072 m、标签面名义 0.059 m，均装车实测；配置标签偏移和车体包络。仓库运行默认值仍为 V11，数据库保存值也不会自动迁移。4 mm 白边、实际光照和运动下都要检测。
6. **四车围堵**：一辆通过后再复制其余三辆，配置唯一车辆 ID 与标签 ID。先双车、再四车，测实际延迟和停止距离。共享相机、服务器、AP 和算法进程即可，不需每车树莓派。

速度提升时要同步扩大制动距离。例如 0.6 m/s、实测可用减速度 1 m/s²、反应延迟 0.2 s，对应 `v²/(2a) + vτ = 0.30 m`，还要加定位误差和余量；这些数值只是公式示例。3 × 3 m 场地可供四车实验，但速度上限必须由实测停车、相机帧龄和控制周期共同决定。

## 9. 文件与复核边界

`review.py` 直接读取 DXF，核对毫米单位、闭合轮廓、精确孔位、开放轮槽、槽尺寸、球轮法兰覆盖、最小材料桥和 ZIP 内容；使用历史主板轮廓/元件包络重算局部净空与条件质量模型，并生成 `audit_results.json`、`audit_layout.png`、`exploded.png`。报告记录 DXF 与主板 STEP 来源的 SHA-256。不会修改加工图纸，不依赖个人 Downloads 路径，也没有把图稿检查写成实车验收。

`references/` 保存的是历史提取的包围盒与板边坐标，含供应商来源和提取方法；未附供应商完整 STEP/STL。它们不是独立重新验证过的硬件测量。PCB 在图中用 1.6 厚示意，真实安装面、孔区厚度需实测；采购件外观、完整线束及标签固定方式未作实体建模。爆炸图沿装配方向展开，层间距离不能作为尺寸。

从仓库根目录运行：

```sh
uv run --with ezdxf --with shapely python hardware_design/acrylic_95/review.py
uv run python hardware_design/acrylic_95/tag_images/generate.py
# 供文档网站使用的同版图片
cp hardware_design/acrylic_95/audit_layout.png docs/public/images/acrylic-95-audit.png
cp hardware_design/acrylic_95/exploded.png docs/public/images/acrylic-95-exploded.png
npm run docs:build
```

也可在独立环境安装 `hardware_design/requirements.txt` 后运行 `review.py`；标签脚本使用仓库 Python 环境中的 Pillow、numpy 和 OpenCV（`cv2.aruco`）进行数字解码。CJK 字体影响图中文字显示；macOS 默认选择 Arial Unicode MS，其他系统可安装 Noto Sans CJK SC。
