# ACField reference hardware

The public reference is [V11](print_v11/README.md). It contains two printable parts, editable generation/audit sources and nominal purchased-part envelopes. First-article fit, strength, rolling resistance and physical control behavior remain unverified.

See the [hardware guide](https://yaoqih.github.io/acfield/hardware/overview) and [bring-up procedure](https://yaoqih.github.io/acfield/hardware/bringup). The original project contains older design iterations; they are intentionally excluded from this curated platform repository.
