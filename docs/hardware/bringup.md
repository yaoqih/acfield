# 固件与首车验收

先把一个完整控制链路测清楚，再复制其他车辆。当前普通固件 0.2.9 允许电机输出（`motorsEnabled=true`），默认编码器轮速闭环（`motorClosedLoop=true`），起始参数为 `feedForward=250`、`kp=60`、`ki=0`。左右编码器每圈计数当前均为 `88`，计数、方向、PI 参数和实际限速仍需逐车实测标定；首次上电应先架空测试。

四辆车现已从 A12、12 V、1:100 更换为同系列 1:20 编码电机。34 mm 轮配名义额定 500 rpm 对应约 0.89 m/s；固件线速度及轮速上限为 0.89 m/s、角速度上限为 6.00 rad/s，主控默认限速为 0.50 m/s、1.50 rad/s。加速度限制已移除。当前 `wheelChannels={0,1}` 同时将逻辑左/右电机与编码器映射到 A/B 通道，应按每车接线核对。

## 配置与构建 {#configure-and-build}

安装 PlatformIO，在仓库根目录执行：

```bash
python3 -m pip install platformio==6.1.18
cp esp32_software/firmware/include/secrets.example.h esp32_software/firmware/include/secrets.h
# 在 secrets.h 填写 Wi-Fi 和主控 IPv4；该文件被 Git 忽略
pio run -d esp32_software/firmware -e general-driver
```

`general-driver` 是 car-01，其余是 `car-02`、`car-03`、`car-04`。烧录时明确选择环境：

```bash
pio run -d esp32_software/firmware -e car-02 -t upload
pio device monitor -d esp32_software/firmware -e car-02
```

## 分阶段验收 {#staged-acceptance}

| 阶段 | 操作与证据 | 进入下一阶段前确认 |
| --- | --- | --- |
| 断电检查 | 极性、绝缘、保险、紧固、三点接地、球轮和线束空间 | 物料与接线匹配，无擦地与松动 |
| 禁止输出 | 手转左右轮记录若干整圈计数；万用表交叉检查电压 | 分别填写真实计数，排除 VCC/GND 图纸冲突 |
| 架空低速 | 左右电机/编码器方向、前进与左转、PI 初调 | 反馈符号正确，无持续发散或异常 |
| 单车落地 | 最低稳定速度、直行/原地转向、停止时间与距离 | 在当前地面可控，保护假设符合测量 |
| 相机联动 | 全场位置/航向误差、帧龄、遮挡与相机移动 | 不可信定位能导致失效，恢复不自动解锁 |
| 故障注入 | 断网、停主控、编码器异常、欠压、设备重启 | 停车与锁定符合规则，故障原因可见 |
| 双车到四车 | 身份、控制权、联合动作、车距保护、持续运行 | 保存运行记录，再接自动策略 |

实际电机每圈计数必须按固件使用的单相上升沿计数方法测量，不能套用商家四倍频数值。左右轮分开标定。电机、编码器和电源优先使用已购成品转接线；散装端子和压线工具不属于首车验收的必需物料，但每根线的针序仍要逐线核对。

## 关键硬件边界 {#important-hardware-boundaries}

当前参考引脚、电压阈值和诊断细节见 [固件 README](https://github.com/yaoqih/acfield/blob/main/esp32_software/firmware/README.md)。电机/编码器接线应按针号与实测确认，不能只按线色。

3S 欠压保护初值是总压低于 10.5 V 持续 1 s 锁存停车；总压不能替代逐节监测。实体断电开关和电源保护属于装配方案的一部分。首车还应核对满充供电、温升与电池固定。

## 怎样量出参数 {#measurement-procedures}

先用[兼容表](./compatibility)确认硬件。每项至少重复 3 次，保留原始读数、均值和最大偏差。下表是低速首车的**示例验收目标**，按任务精度和场地调整，并在测试前写下。

| 测量 | 操作与计算 | 示例验收目标 |
| --- | --- | --- |
| 输出轴计数 | 关闭运动输出，标记轮胎，手转 10 整圈，分别记左右原始计数差；`counts=abs(差值)/10` | 3 次相差不超过 1%，前进反馈经 `encoderSign` 修正后为正 |
| 有效轮径 | 落地推行 10 圈，量距离 L；`D=L/(10π)`，保持实验受载状态 | 3 次相差不超过 1% |
| 有效轮距 | 低速原地转一整圈，独立测转角 θ，记左右轮路程；`B=(s_right-s_left)/θ`，θ 用弧度 | 更新参数复测，转角误差不超过 5°/圈 |
| 直行速度 | 0.03、0.05、0.10 m/s 各运行 5 s，留足停车空间；比较中间 3 s 的视觉和编码器均速 | 两种速度差与目标误差均不超过 10%，无反复起停 |
| 标签偏移 | 量轮轴中点到标签中心的前/左距离；固定轴中点，手转 0°/90°/180°/270° | 校正后位置最大漂移不超过 10 mm |
| 停止时间与距离 | 从稳定 0.05、0.10 m/s 发停止，录像并记日志；从请求量到静止 | 记录 3 次最大值，小于预先留出的停车距离 |

计数使用单相上升沿定义。轮距估计依赖轮程标定，打滑会产生偏差，需在实验地面复测。速度测试前核对真实外廓与可用场地。

### PI 怎么调 {#pi-tuning}

先确认计数、轮径、方向和线材稳定。保持 `ki=0`，低速阶跃时同时记录目标轮速、实测轮速和 PWM。先调前馈使均速接近目标，再小幅提高 `kp`，比较稳态误差与反复加减速。反馈突跳时先检查计数和供电。

每次只改一个参数。选定后重复直行、转向和停止测试，再确定主控限速。当前仓库参数见[默认值](../reference/defaults)。

## 留下最小测量记录 {#keep-a-minimal-measurement-record}
