# 场地与相机布置

参考布置采用 **3 × 3 m** 方形有效场地：在一侧边界外竖立固定杆，顶部以直角横臂延伸到场地中心，末端安装向下俯拍的摄像头。Server 电脑与路由器放在场外。

这里的“场地”包含三部分：车体可以运动的 **3 × 3 m 有效区域**、支撑相机的方管支架、以及场外的 Server 与网络设备。方管长度和连接件目前是采购候选，横臂跨度、立杆高度和底座形式仍应按相机视场、场地边界和现场承重条件确定，候选物料表不能替代最终结构图。

图形源文件与生成脚本位于 [hardware_design/figures](https://github.com/yaoqih/acfield/tree/main/hardware_design/figures)。

| 项目 | 布置 |

| 有效场地 | 3.0 × 3.0 m，坐标范围可设为 x、y 均为 0–3 m |

按上述参考数量，方管合计约 8.2 m，但并不代表可以直接拼出稳定的“立杆 + 横臂”。最终结构至少要确定：相机光轴是否位于场地中心、横臂是否会下垂、底座是否压住边界、相机线是否沿支架固定，以及车辆是否会撞到立杆或线缆。

## 图像与网络连接 {#image-and-network-connections}

```text
俯拍摄像头 ── USB / 有线图像连接 ── Server 电脑
                                     │
                                 Ethernet / LAN
                                     │
                                路由器 / AP
                                     │ Wi-Fi / UDP
                            car-01 … car-04
```

摄像头有线接到电脑；图像线沿横臂和立杆固定后引向场外。图示以 USB 相机为例，最终线材与长度按相机接口确定。`apriltag_live.py`、`robot_server` 和策略脚本可以运行在同一台电脑。

电脑通过网线连接路由器，四台小车接入同一实验 Wi-Fi；路由器承载控制与遥测的局域网通信。电脑端配置视觉服务地址与车辆绑定；从其他机器使用 SDK 时，使用 Server 电脑的局域网 IP。详见[运行与配置](../guide/configuration)。

推荐的布线顺序是：相机沿横臂和立杆固定到场外电脑，电脑用网线连接 AP，车辆只保留 Wi-Fi 无线链路。电池到车端控制板的电源线应避开编码器线和轮胎，转接线每一处都要标记正负极；不应把 USB 相机线、网络线或充电线临时横穿有效区域。

## 相机高度与覆盖范围 {#camera-height-and-coverage}

选择高度时，要同时覆盖地面边界、地面标签完整白边及车顶标签平面：95 mm 亚克力候选名义高约 59 mm，旧 V11 约 64.6 mm，最终按实物测量。对垂直俯拍的理想针孔相机，某方向的覆盖宽度近似为：

```text
覆盖宽度 ≈ 2 × (H − 标签平面高度) × tan(该方向视场角 / 2)
```

使用实际采集分辨率下的水平、垂直视场角分别核算，不能只看镜头宣传中的对角视场角。覆盖范围要留边，并检查四角畸变与最远标签像素；升高相机会扩大范围，同时降低标签像素数。

H200S 的“110°”是商品标称广角参数，不能直接当作实际水平或垂直视场角。安装后应在真实分辨率下拍摄四角和车顶标签，记录最远标签的黑框像素、畸变和运动模糊，再决定是否升高相机或降低有效区域。相机仅改变安装位置时需重新标定场地外参；更换相机、镜头、焦点或采集分辨率时，需重新核对内参并标定外参。H200S 的设备读回范围见[相机参考参数](./h200s-camera)，网页参数以当前驱动支持与读回结果为准。

图中地面 ID 0–3 仅为位置示意，最终中心坐标、朝向和尺寸必须实测后写入配置。全场定位精度、帧龄和相机移动后的失效行为，按[视觉定位与标定](../guide/localization)逐项验证。
