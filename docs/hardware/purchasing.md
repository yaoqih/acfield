## 下单前核对 {#before-ordering}

| 项目 | 本清单与现有方案的关系 |
| --- | --- |
| 电机 | 本次选项为 **1:30**，现有车辆和设计记录为 **1:20**；换型后重新测量编码器计数、带载轮速并更新控制参数。 |
| 电池与充电器 | 选项为 **3S 1200 mAh**；确认充电器适配 3S / 12.6 V、允许充电电流及转换头极性。 |
| 万向轮 | 当前链接指向与主控板相同的商品 ID，需向商家确认 CY-12B 选项。 |
| 支架 | 直通件数量未提供；圆柱夹与方管的适配、连接件锁紧方式按最终支架图确定。 |
| 柱高与图纸 | M3×50 与现有 45 mm / 15 mm 柱高不同；加工前核对装配高度。 |
