# 硬件版本与兼容

**先确认车上装的是什么，再复制参数。** CAD 修订、电机减速比和视觉配置分别记录，更换其中一项就复核对应测量。

## 当前方案 {#matrix}

| 项目 | V11 参考车体 | 95 × 80 mm 紧凑候选 | 新购 1:30 配件 |
| --- | --- | --- | --- |
| 状态 | 公开 CAD 与历史运行配置 | 已提供板件、图纸与标签，首件装配待验收 | 采购规格，整车适配待验证 |
| 电机 | 车体修订独立于电机版本；现有四车报告换为 1:20 | CAD 按 1:20 布置 | 1:30，需重新测输出轴每圈计数和速度 |
| 标签黑框 / 成品 | 104 / 130 mm | 72 / 80 mm，四周白边 4 mm | 随实际车体和标签配置 |
| 标签高度 | 名义 64.6 mm | 名义约 59 mm | 装配后实测 |
| 标签前向偏移 | 名义 16 mm，主控默认仍为 0 | 名义 30.5 mm | 按轮轴中点实测 |
| 立柱 | 按 V11 CAD | 设计按 45 / 15 mm | 新购 M3 × 50 需核对层高与螺钉 |
| 电池 | 按实际装配记录 | 核对托盘、线束和重心 | 1200 mAh 3S，核对尺寸与固定 |
| 已知待核对项 | 实际外廓、偏移、计数 | 标签安装孔与图案的冲突、白边实拍、整车干涉 | 电机安装、立柱高度、电池空间、计数和限速 |

紧凑候选的顶板尺寸不等于整车外廓。`length/width` 要包含车轮、线束和突出件。标签安装孔冲突仍需首件核验后修订，采购前结合[资源与图纸](./resources)检查。

## 更换后改哪里 {#changes}

| 改动 | 重新测量与更新 |
| --- | --- |
| 电机、减速比、编码器 | 固件 `pulsesPerTurn`、通道与符号、前馈/PI、稳定速度；主控限速 |
| 轮径、轮距 | 固件 `wheelDiameter/trackWidth`，直行距离与原地转角 |
| 标签、顶板、立柱 | 视觉黑框尺寸、高度、航向；主控标签偏移、矩形包络和偏移 |
| 相机、镜头、采集模式 | 内参、外参、全场误差；核对驱动实际读回值 |
| 电池与供电 | 固定、负载压降、欠压设置、电量换算 |

按[首车验收](./bringup#measurement-procedures)逐项测量。当前固件默认值见[自动生成参数表](../reference/defaults)，它们描述仓库配置。采购细目见[BOM](./bom)与[购买选项](./purchasing)。
