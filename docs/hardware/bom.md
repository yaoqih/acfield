# 详细 BOM 与采购规格

整理日期：2026-11-15。按重要程度排序：**主控与动力电源 → 车体加工与装配 → 视觉与相机支架 → 端子耗材与工具**。本页记录本次提供的商品链接和选项，未实时核验商品库存、价格或实际下单状态。

**数量口径：**“单车 / 四车需求”用于差速车配置估算；“采购单位与数量”区分用户明确数量与建议采购量。未注明总采购数量的商品，不视为已买。共享设备不乘车辆数；包装数量不等于装车用量。除相机 5 m 线加价 ¥20 外，本次未提供报价，不沿用旧购物车价格计算总价。

## 优先核对的规格 {#priority-checks}

| 项目 | 本次选择及需核对的内容 |
| --- | --- |
| 电机版本 | 本次指定 **A12、DC 12 V、1:30**。原 95 mm CAD 与历史验证车记录为 1:20；本页不表示已经更换实车或软件参数。更换后重测编码器计数、带载轮速与控制限速。 |
| 电池与充电器 | 本次为 **102050×3S、1200 mAh**，不是旧 2200 mAh / XT60 参考。充电器选择 1 A + XH2.54 反向母座转换头；确认适用 3S、12.6 V 充电终止电压、实际电池允许充电电流与极性。“反向”不是通用针序。 |
| 电机接线 | 商品选项写“3线编码电机”，现有图片展示 **6 线、AB 双相、ZH1.5-6P**。尺寸图 PIN5 一行同时写 GND 与 VCC，不能照该文字直接接线；板端为 PH2.0-6P，需逐线确认对应关系。 |
| 尼龙柱与 CAD | 本次是 **M3×50、10 只/包**。95 mm 候选图纸需要每车 M3×45 外柱 4 根与 M3×15 悬挂柱 4 根；50 mm 不能直接视作该图纸的已适配替代。 |
| 相机夹具 | U 型夹选项为夹约 Ø30 mm 圆柱，支架管材是 20×20 mm 方管；夹持形状、范围、适配件和防转固定方式尚未确认。相机另备注 1/4 螺孔。 |
| 链接与缺失数量 | 万向轮与主控板提供的是同一商品链接，需确认是否有 CY-12B 对应选项；20×20 直通（4孔）未给采购数量，先保留待确认。 |
