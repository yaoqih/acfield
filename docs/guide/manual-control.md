# 手动控制

控制台 `/`、手机页 `/mobile` 和编码器页 `/encoder` 共用车辆状态与控制权。每台车同一时刻由一个控制源持有。

## 方向与响应 {#steering}

摇杆按车头方向工作。上前进、下后退，左右横向原地转动，斜向走弧线。右前方时左轮目标更快；倒车左后方时，车尾朝左后方运动，车头朝相反一侧转动。

| 输入区域 | 响应 |
| --- | --- |
| 前后方向两侧各 45° 内 | 行驶弧线，内轮保留至少平均轮速 30% 的同向目标 |
| 横向上下各 20° 内 | 原地转向，线速度为零 |
| 上述区域之间 | 平滑混合行驶与旋转，内轮经过零速 |

行驶转向上限为有效角速度上限与 1.5 rad/s 的较小值，直行附近响应较柔和。纯横向满幅使用车辆完整有效角速度上限。推杆幅度控制速度大小。

## 开始与停车 {#lifecycle}

新输入自动完成控制握手。松手请求停车，方向键松键或摇杆失去键盘焦点会清除按键。空格在输入框外触发全局停止。

页面失焦或切后台本身不锁车，触摸松手与指针取消会停止当前输入。停车、断线和过期会清除待执行输入，重连后重新操作。释放全局停止后也需新输入。

## 发送与执行 {#timing}

摇杆通过有序 WebSocket 每 25 ms 发送最新目标，TTL 为 300 ms。网页省略执行时间，主控对已同步设备预留 60 ms，未同步时即时发送。demo 立即采用目标，实车延迟需测量。

普通固件默认编码器闭环，当前参数见[仓库默认值](../reference/defaults)。编码器页的持续 PWM 诊断流程见[故障排查](./troubleshooting#encoder-diagnostics)。
