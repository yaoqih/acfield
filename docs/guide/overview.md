# 平台概览

ACField 是 AClab（算法与协作实验室）维护的开放式多机器人实验平台。参考配置是四台室内差速小车、一个固定相机和一台主控电脑。它提供从定位到速度执行的基础链路，供研究者接入自己的控制与协作算法。

## 平台负责什么

平台汇集位置与设备状态，接受单车或联合速度命令，管理控制权、显式解锁、有限指令有效期和失效停车，并记录运行事件。Web 控制台是调试入口，HTTP 接口是算法接入入口。

论文中的策略、训练过程、任务定义和统计分析可以作为独立实验代码，依赖一个固定的 ACField 版本。这样基础设施持续改进，已发表实验仍有明确的软件依据。

## 当前组成

```text
固定相机 → AprilTag 服务 → 控制服务 → Wi-Fi / UDP → ESP32 → 编码器电机
                              ↑                     │
                        Web 页面 / 策略              └─ 遥测反馈
```

演示模式由主控中的简化运动模型提供状态，不依赖相机、设备或云服务。视觉模块另有合成图像演示，两者是独立的调试入口，没有自动联动。

## 使用前的共识

当前版本是开发预览。默认四车是参考规模；配置模型允许更多车辆，并不代表更大规模已经测量验证。参考硬件是待首件实测的设计，软件检查与实物性能在[验证状态](./status)中分别说明。
