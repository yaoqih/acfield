# 引用与许可

ACField 由 **AClab — Algorithms and Collaboration Lab（算法与协作实验室）** 开发和维护。

## 引用

如果平台支持了你的研究，请引用仓库，并注明实际使用的提交或版本。GitHub 会根据根目录 `CITATION.cff` 提供引用入口。目前没有为本项目声明论文或 DOI。

```bibtex
@misc{acfield,
  author       = {{AClab}},
  title        = {{ACField}: An Open Multi-Robot Testbed for Multi-Agent Control},
  howpublished = {https://github.com/yaoqih/acfield},
  note         = {Specify the commit or release used}
}
```

建议在论文实验材料中同时注明硬件修订、标定依据、平台保护设置与实验仓库。未来正式发布版本可归档并取得版本 DOI。
